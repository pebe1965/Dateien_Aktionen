## Neu in 1.8.0

* **Update direkt im Programm:** Gibt es eine neue Version, genügt künftig ein Klick auf „Jetzt direkt updaten“. Das Programm lädt die neue Version, ersetzt sich selbst und startet neu – ohne DMG-Datei herunterladen und in „Programme“ ziehen. Klappt etwas nicht, bleibt die bisherige Version unverändert. Der Download der DMG-Datei steht weiterhin zur Verfügung.
* **Sichere Verbindungen:** Auf Macs, deren Python keine Zertifikate mitbringt, prüft das Programm die Verbindung zu GitHub und zum KI-Dienst jetzt mit den Zertifikaten von macOS, statt die Prüfung abzuschalten.
* **Handbuch ergänzt:** Kapitel „Updates“ beschreibt beide Wege, dazu Hilfe, falls das Direkt-Update einen Fehler meldet.

Wichtig: Diese Version musst du noch einmal wie gewohnt installieren. Ab dann funktionieren Updates direkt im Programm.

Installation: DMG öffnen, App in „Programme“ ziehen (bei Nachfrage „Ersetzen“). Einstellungen, Verlauf und Zugangscode bleiben erhalten.
